**Date:** 2026-05-22
**Stage:** 3 — SEO Planning
**Location:** Atlanta, GA
**Niche:** Roofing Contractor (Residential and Commercial)

---

## Executive Summary

New Image Roofing Atlanta has a solid foundation: 114 Google reviews at 4.7 stars, BBB A+ accreditation, Owens Corning Platinum Preferred status, and 14 years in business. These are genuine differentiators. The business is not maximizing them online.

The current website blocks automated audit tools (HTTP 403), which itself is a technical concern: legitimate search engine crawlers and review aggregators may face similar friction. The SEO opportunity is significant. Conservative modelling shows an incremental $21,000/month in revenue potential from organic search improvements alone.

## 1. Technical SEO Assessment

**What we know:**
- Site is live and indexed (appears in search results)
- HTTPS is enabled
- CMS is WordPress (inferred from logo URL structure)
- Website returns 403 to automated crawlers

**Confirmed technical gaps:**

| Issue | Severity | Action Required |
|---|---|---|
| Site blocks automated crawlers | High | Review robots.txt and server-level bot blocking rules. Legitimate SEO bots (Googlebot, Bingbot) must not be blocked. |
| Schema markup status unknown | High | Run Google Rich Results Test manually. Implement LocalBusiness, Service, AggregateRating, FAQPage schema on all key pages. |
| Page speed unconfirmed | Medium | Run PageSpeed Insights on homepage, roof-replacement page, and contact page. Target LCP under 2.5s mobile. |
| Mobile usability unconfirmed | Medium | Run Google Mobile-Friendly Test on homepage and top service pages. |
| Internal linking structure unknown | Medium | Ensure every service page links back to homepage and to 3+ related city pages. |
| Title tags and meta descriptions unconfirmed | Medium | Audit all page title tags for keyword inclusion. Meta descriptions should be 150-160 characters with a CTA. |
| XML sitemap status unknown | Low | Confirm sitemap.xml exists and is submitted to Google Search Console. |
| WordPress version and plugins | Low | Older WordPress installs accumulate security and performance debt. Student should confirm all plugins are current. |

**Priority technical action:**
Before launch, run the new site through Google Search Console, PageSpeed Insights, and the Rich Results Test. The 403 issue on the current site may be causing Google to treat it as low-confidence, depressing rankings despite the strong review profile.

## 6. Top 3 Priorities

### Priority 1: GBP Review Velocity Campaign
**Why:** Review count is the single most controllable ranking factor for local pack. Moving from 114 to 200+ Google reviews will materially improve 3-pack visibility without any technical work. New Image has the quality to earn 5-star reviews. The system to collect them is missing.
**Action:** Build a post-job review request workflow. After every completed job, send the customer a direct link to the Google review form via SMS. Train field crews to verbally ask. Target 200 reviews within 6 months.
**Estimated effort:** 2 hours to set up automation. Ongoing.
**Estimated revenue impact:** First step toward 3-pack ranking. Each 10-review increment improves local pack position.

### Priority 2: Dedicated Storm Damage and Insurance Claims Pages
**Why:** Storm damage and insurance claim management is New Image's genuine competitive advantage. Competitors have this content; it is unclear if New Image does (site inaccessible). The new site will have dedicated pages at /services/storm-damage and /insurance-claims. These two pages should rank quickly given the lower keyword difficulty (35 and 32) versus core money keywords.
**Action:** Launch with 600+ word storm damage page, 600+ word insurance claims page, and an alias redirect at /storm-damage. Include FAQPage schema. Feature the Storm Watch Program by name.
**Estimated effort:** Already covered in copy deck.
**Estimated revenue impact:** 2-3 incremental leads/month from these keywords alone.

### Priority 3: Schema Markup on Every Page
**Why:** Rich snippets (star ratings in search results) increase click-through rate by 20-30% without changing rank position. If competitors show star ratings and New Image does not, clicks go to competitors even when New Image ranks the same or higher. LocalBusiness, AggregateRating, and FAQPage schema are standard requirements and likely missing from the current WordPress site.
**Action:** Implement schema on every page at launch. Use the 4.7-star Google rating and 114 review count in AggregateRating schema. Add FAQPage schema to all service pages.
**Estimated effort:** 2-4 hours technical implementation.
**Estimated revenue impact:** 20-30% improvement in organic CTR across all ranked pages.
