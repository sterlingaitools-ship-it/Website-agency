# SOP brand-dna - Brand DNA Extraction

Implements: Stage 7.

## Purpose

Extract a validated brand-dna.json from the client's logo, existing assets, and research data. Populate all 32 canonical fields in the brand-dna shape contract. The output drives every visual decision in Stage 10 build: palette, typography, shape mode, hero mood, corner overlay, and copy defaults.

## Procedure

1. Read design-synthesis/SKILL.md. Run the five-pass synthesis: logo palette extraction, typography pairing, hero mood assignment, motif selection, shape mode decision.
2. Extract dominant colors from the client's logo. If the logo is navy or dark blue, confirm primary = that color. If the logo uses an orange or yellow accent, confirm accent = that color. If neither, default to niche palette: primary #1a2e4a, accent #f5a623.
3. Assign typography. If the client has an existing font in their assets, use it for heading. If not, default to Montserrat (heading) + Inter (body) — the niche default established in the niche playbook.
4. Assign shape_mode. Roofing is a functional, industrial niche. Default to sharp (4px border radius) unless the client's logo is heavily rounded or soft in form.
5. Assign hero mood from hero-mood-mapping.json. Default: "trust" (daytime, crew on roof, suburban home background). Override to "emergency" only if the client explicitly markets 24/7 storm response as their primary service.
6. Populate all required fields. No __REQUIRED__ sentinels may survive in brand-dna.json after this stage.
7. Write extraction-report.md alongside brand-dna.json documenting confidence scores per field.

## Pass criteria

- All 32 canonical fields populated (validate-brand-dna.mjs passes with zero warnings).
- Confidence aggregate >= 0.70. If below, halt for human review via /approve-brand-dna.
- palette.primary is a dark color with sufficient contrast against white text (WCAG AA minimum 4.5:1).
- palette.accent is a high-contrast color suitable for CTA buttons (WCAG AA against both primary and white backgrounds).

## When this stage halts

- No logo found in assets: halt. Stage 4 (asset scraper) must be re-run before brand DNA can be extracted.
- Confidence aggregate below 0.70: halt and surface /approve-brand-dna for student review.
- Logo is unusable (corrupt file, wrong format, too small): halt and flag to student.

## Niche-specific notes

The roofing niche has a well-established trust palette: deep navy or dark slate blue as the primary, high-contrast orange or yellow as the accent. This combination signals authority, reliability, and urgency — exactly what homeowners respond to when evaluating contractors.

Deviations from this palette are allowed but require a deliberate reason. If a client's brand uses red as primary, that is fine — but confirm the accent still provides sufficient contrast for CTA buttons. Green, purple, or pastel primaries should be flagged to the student before accepting, as they move away from the trust signals the end customer expects in this niche.

Shape mode should almost always be sharp (4px) for roofing. A roofer is not a spa or a lifestyle brand. Sharp corners signal precision and reliability. Softened corners (8-12px) are acceptable only if the client's logo and overall brand direction is explicitly warm and community-oriented.
