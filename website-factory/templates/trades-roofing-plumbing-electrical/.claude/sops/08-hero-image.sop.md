# SOP 08 - Hero Image

Implements: Stage 9.

## Purpose

Generate the branded hero image for the roofing contractor site. The image is the most conversion-critical visual asset on the page — it appears above the fold on the right half of the hero section and must convey credibility, activity, and local identity within two seconds of a homeowner landing on the page.

## Inputs (per-client)

```
clients/[Client Name]/[Client Name] Assets/crew-on-roof-*.{jpg,webp}
clients/[Client Name]/[Client Name] Assets/logo.{svg,png}
clients/[Client Name]/Pipeline Data/brand/brand-dna.json
templates/trades-roofing-plumbing-electrical/niche-playbook/hero-composition.md
templates/trades-roofing-plumbing-electrical/niche-playbook/hero-mood-mapping.json
website-factory/.claude/skills/nano-banana/SKILL.md
```

## Procedure

1. Read hero-composition.md and hero-mood-mapping.json. Identify the assigned hero mood from brand-dna.json (default: "trust").
2. Read nano-banana/SKILL.md. Follow the prompt construction procedure exactly.
3. Check for client-supplied crew photos in assets. If present, use them as multimodal reference images in the Gemini API call. If absent, construct the prompt to describe the crew and scene without reference images.
4. Build the hero image prompt per the niche composition spec: crew on pitched residential roof, mid-action (measuring or installing shingles), 2-3 crew members visible, suburban US home background (single-story or two-story, typical neighborhood), natural daylight or golden-hour light, camera angle slightly below roof line looking up at crew.
5. Send the API call via the direct Gemini Image API. Output size: 1500x700px.
6. Save result to clients/[Client Name]/Pipeline Data/hero-image/hero-final.png (or .webp).
7. Review output against the composition checklist: crew visible and active, home background recognizable, no staged poses, no dark or stormy sky (unless mood = emergency), no stock-photo aesthetic.

## Pass criteria

- Image is 1500x700px minimum.
- At least one crew member is visibly working (not posed, not standing idle).
- Background shows a residential home, not a commercial building or abstract background.
- Lighting is natural (daylight or golden hour). No dramatic studio lighting.
- No text or watermarks in the image.
- Image saved to the correct output path.

## When this stage halts

- Gemini API call fails: retry once, then halt and flag to student with the error output.
- Output image fails the composition checklist on crew visibility or background: regenerate once with adjusted prompt, then halt if still failing.
- No crew photos available and brand-dna indicates a very small operation (1-person crew): flag to student that a generic exterior roofing shot may need to be sourced manually.

## Niche-specific notes

The single most common failure in roofing hero images is the stock photo aesthetic: a crew standing still in pristine uniforms against a perfect blue sky. Homeowners have seen this image on hundreds of contractor sites and it registers as fake. The prompt must specify mid-action: hands on shingles, measuring tape out, nail gun in hand.

The home background matters. A generic white house on a green lawn is acceptable. An obviously commercial building is not — this template serves residential contractors. If the client has a specific city, include a reference to the regional housing style in the prompt (e.g., "brick colonial home typical of Chicago suburbs" or "stucco ranch-style home typical of Phoenix").

Storm damage variant (mood = emergency): dark overcast sky, visible storm damage to the roof (missing shingles, water staining), crew arriving to assess. Use only when the client's primary marketed service is storm damage and insurance claims.
